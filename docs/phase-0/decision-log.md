## No-invention gate

No planned scene depends on an invented screenshot, invented metric, or unanswered product capability. Where evidence is missing, the later implementation must use one of:

1. an approved authentic capture;
2. a clearly labeled decorative interpretation with semantic proof outside the image; or
3. a typography-led composition with no media claim.
