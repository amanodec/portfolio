# Phase 0 Living Signal storyboard

Status: approved Zestt-first direction for Phase 1. These stills are planning plates, not production screenshots and not product proof.

## Shared storyboard grammar

- **Background:** void atmosphere, grid, noise, or project-color field.
- **Mid-ground:** the Signal, project geometry, or timeline line.
- **DOM plane:** selectable semantic copy, metadata, controls, links, and proof.
- **Foreground:** rare type fragments, focus-safe labels, or transition masks.
- **Signal thread:** one orange or scene-adapted line/form that travels between scenes and never replaces content.
- **Native input:** native scroll remains authoritative; pointer and touch augment it; the cursor is never hidden.
- **Reduced motion:** composed still or direct color/opacity cut; no scrubbed camera, trails, spring overshoot, or focus displacement.
- **Fast scroll:** seek deterministically to the current progress; no queued replay.
- **Interruption:** settle at the latest known progress and keep all DOM copy readable.
- **Viewport exit:** pause/deactivate scene work; preserve its settled DOM state.
- **Page hidden:** pause rendering, video, and time-based loops; resume without a time jump.

## Scene 3 — Selected worlds

**Beat:** play, then clarity. Four comparable worlds share metadata grammar and match-cut through one line.

**Still plates:** [desktop](storyboard/stills/scene-3-project-worlds-desktop.svg) · [portrait](storyboard/stills/scene-3-project-worlds-portrait.svg) · [reduced motion](storyboard/stills/scene-3-project-worlds-reduced-motion.svg)

- Background: four controlled project atmospheres; orange Signal thread persists.
- Mid-ground: one project-specific environment at a time.
- DOM plane: title, role, stack, verified outcome, normal external link, and an explicit “decorative visualization” note when needed.
- Foreground: scoreboard/ribbon/path type may overlap only within a bounded, readable region.
- Trigger: native scroll progress selects world; pointer/touch adjusts local response; keyboard receives explicit project navigation.
- Start/settle: Zestt order relay → Trading Leagues velocity → DecisionArc branch → Vinayak Bikers road ribbon.
- Scroll allocation: 4 world beats, roughly 120–180vh each; exact values depend on approved storyboard and benchmark.
- Fast scroll/interruption: deterministic match-cut seek; no particle accumulation or replay queue.
- Fallback: four normal-flow project articles with still/typography plates.
- Benchmark dependency: Zestt is the approved first world and must set the proof, fallback, and interaction standard for Phase 3.

## Responsive and fallback summary

| Mode | Desktop | Tablet | Mobile | Reduced motion / no WebGL | No JavaScript |
|---|---|---|---|---|---|
| Scene composition | Full camera/depth, one WebGL context | Shorter camera, fewer objects, tap/focus states | Portrait-specific 2.5D, shorter pins, touch controls | Still/direct cut, no scrubbed camera or pointer trails | Semantic normal-flow sections |
| Text | May cross planes within readable bounds | Less overlap | No clipping; capped rotation/depth | Full copy remains visible | Full copy remains visible |
| Project proof | Authentic media or labeled abstraction | Same order, simplified environment | One world per readable block | Static evidence and links | Normal articles and links |
| Contact | Cinematic path around normal form | Same form, less decoration | Full-width controls ≥44 px | Static path/status | Native form/mailto behavior |
